# Hearthside AI Workplace

Build a modern, responsive SaaS web app called AI Workplace Productivity Assistant that helps professionals save time using AI. Use a premium fawn, beige, cream, and dark brown colour palette, clean typography, rounded cards, subtle shadows, and a polished professional layout.

Create a responsive dashboard with a collapsible sidebar, top navigation, welcome section, productivity overview, and four functional AI tools: Smart Email Generator (Formal, Friendly, Persuasive tones), Meeting Notes Summarizer (summaries, decisions, action items, deadlines), AI Task Planner (prioritised daily/weekly schedules), and AI Research Assistant (topic summaries, insights, recommendations). Include a workplace AI chatbot for interactive assistance.

Each tool must have clear input fields, useful example prompts, a Generate button, structured output, loading states, error handling, and Copy/Clear actions. Make the interface interactive, with working navigation, sample data, and local browser state where useful. Use genuine AI integration only if securely configurable; otherwise provide clearly labelled demo responses that are context-aware and vary according to user input. Do not pretend demo responses are generated by a real AI model.

Frontend only: no backend, database, authentication, or paid services. Use lightweight client-side functionality and local mock data. Include a responsible AI disclaimer reminding users to verify outputs and avoid entering confidential workplace information. Ensure excellent mobile responsiveness, accessibility, and a cohesive, presentation-ready SaaS experience. Build the complete application directly; do not just create a landing page.
